# MQTT Component Model

In MQTT Component Model we stick to the original paper [A Programming Paradigm for Spatiotemporal Composability](https://arxiv.org/abs/2608.25512) in algorithmic part but not in therminological part.
We always prefer our local domain specific therminology over the original paper's and leave references to the original paper's terminology where appropriate.
We use more common sense and MQTT bound therminoloy without overloading with mathematics. Overuse of mathematics frightens the reader and makes the text difficult to read. E.g. we try to use dependencies instead of coeffects, requests/actions instead of effects and so on.
